## 0.34.7 — 2026-11-17

修：编辑台词页点了别的分组，下面的 textarea 还是原来那一组的词。

- 根因：textarea 用的是 `defaultValue`（非受控）。React 复用同一个 DOM 节点时，改 `defaultValue`
  不会写进已经挂载的 `value` —— 只有首次挂载才生效。所以「分组」高亮变了、内容没变
- 修法：给 textarea 加 `key: 'ta-' + editGroup`，切组时重建节点，`defaultValue` 才会重新读一遍
- 另一条路是改成受控（`value` + `onChange`），但那要把每组的编辑缓冲提到 React state、还得处理
  「切组前没保存」的取舍；这个页是一次性编辑，加 key 更小、行为更符合预期
- 新增三条断言：切到洗牌组内容会变、洗牌组就是洗牌那几句、切回关怀组是关怀句（原来只断言「自我关怀」按钮在）
