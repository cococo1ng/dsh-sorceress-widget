# Sorceress · 塔罗挂件

右下角一个会说话的女巫 **Sorceress**（女巫）：抽塔罗、看每日星座与月相、记情绪、查计费账单。
素材全部内联在包里，**不调外部进程**；外网只出计费那一条余额查询（宿主代发，API key 不出宿主），
磁盘只写一份用量账本。

当前版本见 `package.json`（本文不再写死版本号，改版本只需改那一处）。

---

## 装法

DSH 桌面版：把本包放进 profile 的依赖里并加进 `dsh.profile.bundles`，重启后生效。

```json
"dependencies": {
  "dsh-sorceress-widget": "link:<你的路径>/sorceress-widget/plugin"
},
"dsh": { "profile": { "bundles": [ "…", "dsh-sorceress-widget" ] } }
```

装完在 profile 目录跑 `pnpm install`，然后重启 DSH（bundles 是启动时合成的，刷新页面不算）。
**只改前端不用重启**（`python build.py` 后 `Ctrl+R`）；**改了宿主 `index.js` 必须重启**。

## 交互

| 动作 | 结果 |
|---|---|
| 左键点她 | **冒一句随机台词 + 换姿势，不打开面板** |
| 右键 | 同左键（也只是搭一句话） |
| 悬停 / 点右上角水晶球 | **面板入口只有这一处**：悬停人物时浮现，点开面板；点它只开面板，不冒台词（水晶球算她的道具） |
| 按住拖动 | 移动位置，松手记住；拖完不误触点击 |
| 闲置 | 四段：15 秒发呆、一分钟自语一句、久坐五分钟睡着、深夜多说一句关怀；动一下就醒 |
| 缩放 | 配置页四档（0.7 / 1.0 / 1.3 / 1.6），人物与面板同比 |
| 面板头部「今日 ¥x」 | 一眼看当天花了多少，点一下跳到计费页 |
| 拖动面板 | **按住标题栏**把面板拖到任意位置，位置会记住；拖走后标题栏出现「复位」，点了回到人物头顶上方 |
| 收起面板 | 标题右侧「×」或底栏「收起 / 关闭」 |
| 底栏「关于」 | 打开关于页（介绍、隐私与算法口径、QQ 群 127879829、赞赏码）；「返回」回到原页签 |
| 快捷键 | `Alt+S` 开合面板；`Alt+Z` 直接抽一张（只在带 Alt 时接，不影响正常输入） |

## 气泡播报（账）

她会在气泡里报两件事，都走 `/srs/live.json`（3 秒一轮），配置页「气泡」块里各有开关：

| 事件 | 气泡 | 停留 |
|---|---|---|
| 一轮账结完（`seq` 变大） | 「这一轮 ¥0.0321」+ 副行「12,438 tok · chat」 | 8 秒 |
| 有件事在等你（`approval/asked`） | 「等你点个头」+「会话名 在等你授权。」 | 20 秒 |
| 有件事在等你（`ask_user_question`） | 「等你说一句」+「会话名 在等你答话。」 | 20 秒 |

- 页面刚开、后端已经攒了多轮时**只对齐基线不补播**，不会刷你一脸历史
- 价表里没有的模型显示「这一轮没计价 · 只记 token」，不印 `¥0.00`（0 会被读成免费）
- 同一件挂起只吵一次（按 `kind:id` 去重）；播报期间闲置自语与小动作让位，不会把她刚说的话顶掉
- 等待播报同时把姿势换成 想事（答话）/ 翻牌（授权），并敲一声铃

## 播报音效（与塔罗那五路分家）

气泡报账时响三声，各管一件事，都在配置页「播报音」里单独开关 / 试听：

| 事件 | 音效 | 听感 |
|---|---|---|
| 一轮账结完 | `cost` | 两声干爽点数（2.4k / 1.8k 短脉冲带泛音），0.4 秒，电平与铃同档但短得多 |
| 在等你答话 | `ask` | 两句上行木琴（587 → 880Hz），末尾上扬，像一句问话 |
| 在等你授权 | `approve` | 同一低音连敲两下（392 / 196Hz），三路里最沉、最催 |

塔罗那五路（洗牌 / 抽牌 / 翻牌 / 收牌 / 结果铃）只在抽牌流程里响；两边音源不同，可以一边关一边留。

## 计费口径（和 DSH 自己的「总消费」同源）

| 项 | 口径 |
|---|---|
| 记账源 | 宿主监听 `session/event`，按 `(会话, 轮次)` 聚合 `assistant/message` 与 `compaction/summary` 的真实 `usage`，`turn/end` 结算 |
| 计价 | 官价表（元 / 百万 token）× 当时的峰谷档；缓存写入按**未命中**价、缓存命中按 hit 价，输出含 reasoning |
| 峰谷 | 工作日 9–12 / 14–18 高峰，其余空闲；周末与法定节假日全天谷价。放假表覆盖到 **2026 年**，跨年要补表 |
| 未知模型 | 价表里没有的模型**只记 token、不记钱**，界面标「未计价」，页顶提示有几轮 |
| 余额 | API Key（`DEEPSEEK_API_KEY`）优先，失败退宿主账号；余额**只作对照**，不当今日已用 |
| 落盘 | `DSH_HOME/.srs-usage.json`：今日合计 / 逐日汇总 / 逐轮明细（含会话名）/ `turnSeq`；明细留 90 天 · 500 条，挤出去的进 `.srs-usage-archive.json`（上限 2 万条） |

## 素材

- 立绘 **19 张**（idle-a/b · think · dazed · shuffle · spread · draw · flip · smile · sleep · smirk · fly（镜像）· reading · annoyed · bye · **rest-hands 静候 · look-aside 远望 · hold-cup 捧杯 · stretch 伸腰**）、78 张牌面（big + thumb 各一份）、牌背、UI 素材 7 件
- 立绘 / UI / 音效 全部在构建时内联成 data URI；牌面走路由（78×2 张，带 immutable 缓存）
- `client.js` **1716.0 KB**（内联素材 984.5 KB，其中约 71 KB 是「关于」页的两张码），预算已随立绘增加放宽（0.54.0 从 1364 KB 涨到 1611 KB：四张新立绘内联各约 60 KB；0.56.0 再加两张码到 1716 KB）
- **音效全部为真实录音**（Mixkit Free License，清单与 id 见 `NOTICE.md`）：塔罗五路 + 播报三路内联，环境音景八套走 `/srs/sfx` 路由。结果铃是**服务铃一声叮**（0.56 秒、尾巴 0.20 秒，0.52.0 换源）；每轮记账 / 等你答话 / 等你授权三路取的是**柔音档**（谱重心 470–780 Hz、4kHz 以上能量 <4%；「等你授权」用起音 0.07 秒的尼龙弦单音，不拖前奏）
- 牌面版式（深蓝底 + 细金边 + 四角八角星 + 米色卷轴横幅）78 张一致性已量化验证

## 隐私

不上报、不读你的对话内容。本地写入三处：

1. `localStorage` 里的界面设置（`srs.cfg.v1`）
2. `localStorage` 里的私密档案（经期 / 情绪 / 睡眠；PBKDF2 + AES-GCM 加密后）
3. `DSH_HOME/.srs-usage.json` 一份计费用量账本（时间 / 模型 / token / 金额 / 会话名，不含对话正文）

外网请求只有一处：`/user/balance` 余额查询（宿主代发，key 不进客户端）。

## 已知边界

- 计费只对价表内的模型计价；表外模型显示「未计价」，金额会小于真实（宁可少算不瞎算）
- 「按会话」只覆盖还留在账本里的明细（90 天 / 500 条）；已结转进逐日汇总的那部分没有会话归属
- 峰谷与法定节假日表覆盖到 2026 年，之后按工作日/周末算，界面会提示 `holidayOk=false`
- 每日一牌提醒不插队：她正播着账目（这一轮花了多少 / 有件事在等你）时会让一让，等下一轮 30 秒再响；同一天只响一次，当天已经抽过就不再响
- 塔罗解读、星座文案、共情句属于传统文化与娱乐参考，不做医疗、法律、投资判断
